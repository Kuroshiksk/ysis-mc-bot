📜 Sistema de regras

Edite o texto, selecione o canal e publique um embed das regras.

Até 4000 caracteres. Use linhas separadas para organizar as regras.

Regras sugeridas

Se ainda não tens texto, podes usar este modelo e adaptar às regras da comunidade.

🛡️ Criar cargo

Define o nome e, se quiseres, uma cor hexadecimal.

Atribuir cargo

Usa o ID do utilizador do Discord. O bot só consegue gerir cargos abaixo do cargo dele.

Cargos existentes

Os cargos integrados ou acima do bot não podem ser apagados.

# Criar canal

Crie canais de texto, voz ou categorias para organizar o servidor.

Canais existentes

Renomeie, ajuste o modo lento ou apague canais.

📢 Publicar aviso

O bot envia o aviso em formato de embed no canal escolhido.

📋 Registos de ações

Configure um canal para receber logs dos comandos administrativos e ações do painel.

Escolha “Desativar registos” para deixar de enviar logs.

O que fica registado?

Alterações de regras, criação e exclusão de cargos ou canais, atribuição de cargos, limpeza de mensagens e publicação de avisos.
